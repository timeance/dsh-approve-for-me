# dsh-approve-for-me
Codex-style “Approve for me” for DeepSeek Harness: deterministic rules screen requests before a separate LLM reviews sandbox escalations. Approved actions run once; risky, uncertain, or failed reviews fall back to a human—fewer prompts without Full Access. 给 DeepSeek Harness 加上 Codex 风格的“帮我批准”：规则先筛、独立 LLM 复核，风险或不确定请求交回人工。
